# 💻 VickyBuster – Plataforma Interactiva

Este proyecto fue desarrollado como parte del examen parcial de la materia **Plataformas de Desarrollo**, con el objetivo de construir una aplicación web interactiva basada en el concepto de "plataforma".

A diferencia de un sitio web tradicional, VickyBuster permite al usuario crear, modificar y gestionar elementos dinámicos dentro de la interfaz, funcionando como un entorno activo de trabajo.

---

## 🎯 Objetivo del proyecto

El objetivo principal fue aplicar conceptos clave de desarrollo frontend utilizando **JavaScript puro (Vanilla JS)**, implementando:

- Gestión de estado global
- Manipulación dinámica del DOM
- Persistencia de datos
- Procesamiento de información en tiempo real

---

## ✨ Características

- Creación dinámica de elementos desde la interfaz
- Edición y eliminación individual de cada elemento
- Interacción mediante eventos (click, input, etc.)
- Renderizado automático en el DOM
- Filtrado de elementos según criterios
- Cálculos en tiempo real (totales, métricas, etc.)
- Persistencia de datos con LocalStorage

---

## 🧠 Tecnologías utilizadas

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
